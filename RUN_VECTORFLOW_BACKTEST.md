## Reading the Output

Each run produces CSV results in a timestamped folder under `results/`.

**Key columns to look at:**

1. **Trades/day** (printed to console under each config)
   - Should be **single digits** for a reasonable signal
   - If you see 40+/day, the CSV load probably failed
   
2. **Rank, ConfigId, ExitMode** 
   - Top 20 results sorted by Sharpe ratio
   - `Exit=TRAIL` = trailing stop (ride the trend)
   - `Exit=FIXED` = fixed profit target (scalp)

3. **GrossProfit, ReturnPct**
   - Does it approach your live target (~$1k/day)?
   - For 44 days: ~$44k gross = match

4. **LONG vs SHORT split**
   - Are the two directions balanced?
   - Lopsided results suggest a sign error or data issue

5. **MaxDD** (maximum drawdown)
   - Typical ranges: $5k – $20k on a 44-day run
   - Anything over $30k is a yellow flag

## Interpreting Results

### If MNQ and MGC both show positive Sharpe + single-digit trades/day
- ✅ The mechanical VectorFlow method works
- ✅ Ready to deploy as-is (once live NinjaScript is fixed)

### If one works and the other doesn't
- Check the signal CSV quality (# of fires per day)
- Review the TradingView VectorFlow tuning for that instrument

### If trades/day are high (40+) on both
- The signal CSV load failed silently
- Check that TradingView export has BUY/SELL columns
- Re-export and try again
