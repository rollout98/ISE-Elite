DEPLOYMENT GUIDE QUICK START
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. TIMESCALEDB (Docker)
   docker run -d --name timescaledb \
     -e POSTGRES_PASSWORD=postgres -p 5432:5432 \
     timescale/timescaledb:latest-pg14

2. CREATE DATABASE
   psql -U postgres -h localhost
   CREATE DATABASE ise_elite;
   \c ise_elite
   \i C:\path\to\database\ise_elite_schema.sql

3. NINJASCRIPT
   - Add Npgsql NuGet package
   - Copy IseEliteStrategy.cs to Custom/Strategy folder
   - Compile (F5)
   - Add to chart

4. DEPLOY
   - Start TimescaleDB: docker start timescaledb
   - Launch NinjaTrader
   - Watch output: "✅ Database connected"
   - GO LIVE at 9:30 AM
