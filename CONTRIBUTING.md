# Contributing to ISE Elite

## Workflow

1. Create a focused branch from `main`.
2. Make one coherent change per pull request.
3. Add or update tests and documentation.
4. Open a draft pull request early.
5. Merge only after required checks pass.

## Branches

- `feature/*` — product capabilities
- `fix/*` — defects
- `docs/*` — documentation
- `chore/*` — repository and tooling work
- `agent/*` — changes prepared by an engineering agent

## Definition of Done

A change is complete when it is documented, tested, reviewed, traceable to a requirement, and safe to release.
