# ISE Elite V7.9 — Full-Session Scalp Engine Study

Status: research only; no production promotion; no merge authorization implied.

## Purpose

Test whether a prop-compatible, full-session MNQ scalping engine can capture materially more qualified daily opportunity than the current highly selective morning engine.

## Session

- Central Time research window: 17:00 previous day through 15:00 current day.
- Primary execution interval: 1 minute.
- Context intervals: 3 minute and 5 minute derived from the same causal 1-minute stream.

## Initial trade model

- 3 MNQ contracts.
- Study 30-, 40-, and 50-tick scalp objectives.
- No simultaneous positions.
- New entry requires a new qualified micro-opportunity; no blind immediate re-entry.
- Minimum 30-second conceptual holding-time bucket for compliance analysis; historical 1-minute bars cannot resolve sub-minute holding time exactly, so any sub-minute conclusion must be deferred to market-replay/live telemetry.
- Cooldown is measured in completed 1-minute bars and tested as a compliance governor, not as a source of alpha.
- Hard caps are research parameters for trade-density control, not optimization targets.

## Opportunity families to attribute separately

1. Trend impulse / continuation.
2. Pullback / reset continuation.
3. Directional transition / reversal.
4. Mean-reversion only when higher-timeframe context is non-trending.

## Required outputs

- Trades per session and per hour.
- Win rate, average win, average loss, expectancy.
- Net P&L before and after explicit commission/slippage assumptions.
- Max intraday drawdown and consecutive losses.
- Days >= $300, >= $500, >= $1,000.
- Distribution by Central-time hour.
- Distribution by opportunity family.
- 30/40/50-tick target comparison without selecting a winner until all windows are reported.
- 1-minute entry versus 3-minute confirmation delay/capture comparison.
- MFE/MAE and post-exit favorable excursion.
- Trade-density/compliance telemetry: median hold bars, median gap between entries, entries per rolling 5/15/60 minutes, and repeated-signal suppression count.

## Research discipline

The current V7.8.7 frozen forward-validation track remains untouched. V7.9 is a separate research branch. Results must be reported by independent time blocks before any parameter is promoted. The $500–$1,000 daily figure is an objective for available/capturable opportunity, not a forced daily quota.
